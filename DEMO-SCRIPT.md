# 90-second TraceStep walkthrough

This is a recording script, not a claim that a video has been recorded.

**0:00–0:12 — The problem.** Show the empty workspace. “A meeting ends. Three documents remain. What should happen next, and why should we trust it?”

**0:12–0:25 — Input to action.** Click **Try the product-launch example**. “TraceStep works locally, with no account or API key. Three synthetic sources become eight candidates with nine evidence links. This is rule-based extraction, not a language model.”

**0:25–0:43 — Show the evidence.** Review **Review the launch checklist**. Expand surrounding context. “This commitment appeared twice. We merged the duplicate but retained both quotes, source names and line numbers. Editing the action never rewrites the evidence.”

**0:43–0:55 — Human confirmation.** Click **Confirm step**. Scroll to the next-step card. “Only a confirmed, assigned, dated and unblocked step is recommended as ready.”

**0:55–1:10 — Show uncertainty.** Open **Confirm the accessibility test owner by Friday.** “There is no owner, and Friday is ambiguous. TraceStep leaves both unresolved. I choose the actual owner and date instead of letting the tool guess.” Fill synthetic demo values and confirm.

**1:10–1:22 — Useful output.** Export Markdown and save a workspace. “The plan travels with its source quotes. The workspace file lets me resume later. Nothing is uploaded by the app.”

**1:22–1:30 — Honest limits.** “This prototype handles explicit English action patterns and one action per line. It can miss implicit commitments. Its value is a next step that you can inspect, edit and explain.”
