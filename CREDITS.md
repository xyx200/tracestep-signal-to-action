# Credits and disclosure

## New work for this challenge

TraceStep's interface, extraction engine, source-evidence model, exports, synthetic demo notes, behavioral tests and submission materials were created specifically for HackHoster's October 2026 **Signal to Action** challenge. Development began on October 29, 2026 UTC (October 30 in Asia/Shanghai), within the published challenge window.

No earlier project or template was copied into this entry. No third-party runtime library, font, stock image, dataset or paid API is bundled. Icons are typographic characters and the interface is original HTML/CSS/JavaScript. The app uses built-in browser APIs, and optional testing/preview uses Node.js built-ins.

## AI assistance

OpenAI Codex assisted with concept development, original code, interface styling, synthetic examples, tests, debugging and English documentation. Tool-assisted testing and browser interaction were used to inspect the implementation. This is substantial AI-assisted development and is disclosed explicitly.

The application itself runs deterministic pattern-matching rules. It does **not** call a language model, imply model understanding, or require a paid service. The author/entrant remains responsible for reviewing the work and any competition representations.
